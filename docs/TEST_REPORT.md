## เส้นทางใช้งานจริง

ทดสอบด้วย Google สองบัญชีจริง บัญชี A ทำหน้าที่ผู้จัดผ่านเบราว์เซอร์ของ Codex และบัญชี B ทดสอบบนมือถือโดยผู้ใช้ยืนยันผลแต่ละช่วง ข้อมูลทริปสร้างและเปลี่ยนผ่านหน้าเว็บทั้งหมด

| ช่วงใน BUILD_PLAN | ผลและหลักฐาน |
| --- | --- |
| 0 — เข้าระบบ | Google ส่ง A กลับ `/groups` บน Vercel; B เข้าสู่ระบบจากลิงก์เชิญและเข้าหน้าทริปได้ การแก้ Supabase URL Configuration แก้ปัญหากลับ localhost |
| 1 — กลุ่มและคำเชิญ | A สร้างกลุ่ม/ทริปและลิงก์เชิญ; B ยืนยันเข้าร่วม มีผู้ร่วมทริปสองคน; เพิกถอนลิงก์แล้วหน้าเชิญแสดงว่าลิงก์ถูกยกเลิก |
| 2 — โหวต | มีวัน 20/21 ตุลาคมและสวนลุมพินี; ทั้งสองบัญชีส่งวันและสถานที่ครบ หน้าแสดง `2/2`; การส่งคำตอบสถานที่ว่างและแก้ใหม่ไม่เพิ่มจำนวนผู้ตอบซ้ำ |
| 2 — กำหนดเวลา | เปิดหน้าฟอร์มก่อนปิดโหวต 17:45 น. แล้วส่งหลังเวลาฐานข้อมูลผ่านกำหนด เซิร์ฟเวอร์ปฏิเสธด้วย `voting-closed` |
| 3 — ยืนยัน/RSVP | ยืนยัน 20 ตุลาคม เวลา 10:00 น. สวนลุมพินี; ทั้งสองบัญชีตอบไป ได้ยอด 2 คน |
| 3 — เปลี่ยนแผน | เปลี่ยนเวลาเป็น 10:30 น.; `plan_version` เพิ่มเป็น 2 ยอด RSVP เริ่มที่ 0 และแสดงต้องตอบใหม่; ทั้งสองบัญชีตอบใหม่ได้ยอด 2 คน รุ่นที่ 1 ยังเก็บคำตอบเดิมสองรายการ |
| 4 — แชร์/แจ้งเตือน | Clipboard มีชื่อทริป งานที่ต้องทำ เวลาและ URL ถูกต้อง; แจ้งเตือนคำเชิญ/เปิดโหวต/ยืนยัน/เปลี่ยนแผนแสดงได้และทำเครื่องหมายอ่านได้; B ยืนยันเหตุการณ์แผนเปลี่ยนบนมือถือ |
| 4 — สิทธิ์และมือถือ | REST API ที่ใช้ publishable key โดยไม่ล็อกอินอ่านทริปได้ 0 แถว; ทดสอบ viewport 390px ไม่มีความกว้างล้นหน้า; B ทำเส้นทางเชิญ → โหวต → RSVP บนมือถือ |

การกดจบทริปก่อนวันเดินทางสิ้นสุดถูกปฏิเสธบนหน้าเว็บด้วย ลิงก์เชิญที่ใช้ทดสอบถูกเพิกถอนหลังทดสอบ สมาชิกเดิมและ RSVP ยังคงอยู่

## การตรวจอัตโนมัติ

- `npm run build`, `npm run lint`, `npm test`: ผ่าน; Node test runner มี 5 tests ครอบคลุมปลายทาง OAuth, timezone/DST และผลรวมโหวต
- pgTAP ใน `supabase/tests/01_*.sql` ถึง `10_*.sql`: ผ่านบน Supabase ใน transaction ที่ rollback ครอบคลุม RLS, คำเชิญซ้ำ/หมดอายุ/เพิกถอน, ผู้ร่วมทริป, โหวต, ยืนยัน/RSVP, แก้ draft, จัดการสมาชิก, แจ้งเตือน, timezone และจบทริป
- `npx.cmd supabase@latest db start`: สร้างฐานข้อมูล local ใหม่และ apply migrations ทั้ง 13 ไฟล์สำเร็จ
- `npx.cmd supabase@latest test db --local`: ผ่านทั้ง 10 ไฟล์ (`Result: PASS`) หลังแก้ migration ถอนสิทธิ์ helper ให้ตรวจว่าฟังก์ชัน hosted มีอยู่ก่อน จึง replay ได้ทั้ง hosted และ local
