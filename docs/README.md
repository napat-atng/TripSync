# เอกสาร TripSync

เอกสารใน `docs/` เป็นแนวทางสำหรับสร้าง MVP ของ TripSync ตามข้อตกลงล่าสุด: ใช้กับกลุ่มเพื่อนขนาดเล็ก, เริ่มด้วยบริการระดับฟรี, เข้าสู่ระบบด้วย Google และแชร์ลิงก์ผ่านแชตที่ใช้อยู่

| เอกสาร | ใช้เพื่อ |
| --- | --- |
| [STRUCTURE.md](STRUCTURE.md) | เข้าใจขอบเขต สถาปัตยกรรม กติกาหลัก และข้อมูลของระบบ |
| [BUILD_PLAN.md](BUILD_PLAN.md) | ลงมือสร้างตามลำดับ พร้อมเกณฑ์ตรวจรับแต่ละช่วง |
| [features/README.md](features/README.md) | ค้นหาสเปกพฤติกรรมของแต่ละฟีเจอร์ |

`TRIPSYNC_APP_STRUCTURE.md` ที่รากโปรเจกต์เป็นร่างแนวคิดแรก หากรายละเอียดขัดกัน ให้ยึดเอกสารใน `docs/` ซึ่งรวมข้อสรุปหลังทบทวนมุมผู้ใช้และระบบแล้ว
