# 01 — เข้าระบบ สิทธิ์ และลิงก์เชิญ

## เป้าหมาย

เพื่อนเปิดลิงก์จากแชต เข้าระบบด้วย Google และกลับมาที่คำเชิญเดิมได้ โดยไม่มีใครอ่านทริปของกลุ่มที่ตนไม่ได้เข้าร่วม

## พฤติกรรม

- ผู้ใช้เข้าระบบด้วย Google ผ่าน Supabase Auth; สร้างหรืออัปเดต `profiles` จากตัวตนที่ยืนยันแล้ว ไม่เชื่อ `user_id` ที่ส่งมาจากเบราว์เซอร์
- เก็บ URL ปลายทางที่เป็นเส้นทางภายในแอปเมื่อส่งไปล็อกอิน แล้วกลับไป URL นั้นหลัง OAuth callback; ปฏิเสธ URL ภายนอกเพื่อไม่ให้เกิด open redirect
- ผู้ดูแลกลุ่มสร้างและเพิกถอนลิงก์กลุ่มได้ ผู้จัดทริปสร้างและเพิกถอนลิงก์ทริปของตนได้; ทุกลิงก์มีวันหมดอายุ
- หน้า `/invite/[token]` แสดงชื่อกลุ่มและชื่อทริปถ้ามี พร้อมปุ่มยืนยันเข้าร่วม; การเปิดลิงก์อย่างเดียวยังไม่เพิ่มสมาชิก
- รับลิงก์กลุ่มแล้วเพิ่ม `group_members`; รับลิงก์ทริปแล้วเพิ่มทั้ง `group_members` และ `trip_participants` สถานะ `interested` ในคำสั่งเดียว การรับซ้ำสำเร็จโดยไม่สร้างแถวซ้ำ
- เก็บแฮชของโทเคนในฐานข้อมูล ไม่บันทึกโทเคนดิบหรือใส่ลง log; ลิงก์ที่หมดอายุหรือถูกเพิกถอนแสดงเหตุผลที่เข้าไม่ได้

## สิทธิ์และขอบเขตข้อมูล

- สมาชิกกลุ่มอ่านข้อมูลกลุ่มได้; ผู้ร่วมทริปที่ไม่ปฏิเสธคำเชิญโหวตทริปนั้นได้; เฉพาะผู้จัดแก้และยืนยันทริป
- สมาชิกคนหนึ่งอยู่ได้หลายกลุ่ม แต่สิทธิ์ไม่ข้ามกลุ่ม ทุกคำสั่งตรวจทั้งตัวตน สมาชิกกลุ่ม และบทบาทเฉพาะทริปฝั่งเซิร์ฟเวอร์
- RLS ของตารางที่เปิด API ต้องกันผู้ใช้ที่ไม่ได้อยู่ในกลุ่ม แม้เดา ID หรือเรียก endpoint โดยตรง

## เกณฑ์ตรวจรับ

1. B ที่ยังไม่ล็อกอินเปิดลิงก์ทริปของ A, เข้าระบบ Google, เห็นข้อมูลคำเชิญ แล้วกดเข้าร่วมได้
2. B เปิดลิงก์เดิมซ้ำแล้วสมาชิกและผู้ร่วมทริปยังมีอย่างละหนึ่งรายการ
3. C ที่ไม่อยู่ในกลุ่มเปิด URL ทริปโดยตรงแล้วอ่านหรือแก้ข้อมูลไม่ได้
4. ลิงก์หมดอายุ/เพิกถอนแล้วรับเข้าร่วมไม่ได้ และ URL ปลายทางภายนอกไม่ถูกใช้หลังล็อกอิน
