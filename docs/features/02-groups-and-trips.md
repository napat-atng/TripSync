# 02 — กลุ่ม ทริป และผู้ถูกชวน

## เป้าหมาย

คนจัดทริปสร้างกลุ่มที่ใช้ซ้ำได้ แต่เลือกคนที่เกี่ยวข้องกับแต่ละทริปได้ต่างกัน

## พฤติกรรม

- ผู้สร้างกลุ่มเป็น admin คนแรก; admin แก้ชื่อ/คำอธิบาย จัดการสมาชิกและลิงก์กลุ่ม สมาชิกทั่วไปเห็นรายชื่อและทริปของกลุ่ม
- สมาชิกกลุ่มสร้างทริปได้และกลายเป็น organizer ของทริปนั้น; ทริปเริ่มที่ `draft` พร้อมชื่อ รายละเอียด เขตเวลา และเวลาปิดโหวต
- ผู้จัดเลือก `trip_participants` จากสมาชิกกลุ่ม หรือแชร์ลิงก์ทริปให้เพื่อนนอกกลุ่มเข้าร่วม; คนที่เป็นสมาชิกกลุ่มแต่ไม่ได้ถูกชวนไม่อยู่ในตัวหารผลโหวต
- ผู้ถูกชวนมีสถานะ `pending/interested/declined` และกดปฏิเสธได้ตั้งแต่ก่อนโหวต การลงคะแนนเปลี่ยนสถานะ `pending` เป็น `interested` โดยอัตโนมัติ
- ผู้จัดแก้ชื่อ รายละเอียด เวลาโหวต และผู้ถูกชวนได้ขณะ `draft`; หลังเปิดโหวตชุดตัวเลือกและกำหนดปิดโหวตคงที่
- ผู้จัดยกเลิกทริปได้จาก `draft`, `voting` หรือ `confirmed`; แสดงเหตุผลถ้าระบุ หลัง `cancelled` ไม่รับคะแนนหรือ RSVP อีก
- ผู้จัดทำเครื่องหมาย `completed` ได้หลังเวลาสิ้นสุดของวันที่ยืนยันผ่านไปแล้ว; ก่อนหน้านั้นหน้าเว็บอาจแสดงว่าเป็นทริปที่กำลังจะมาถึง
- หากต้องนำผู้จัดออกจากกลุ่ม admin ต้องโอนสิทธิ์ผู้จัดทริปที่ยังไม่จบให้สมาชิกคนอื่นก่อน; สมาชิกที่ถูกนำออกจะไม่ถูกนับในผลปัจจุบัน
- สมาชิกออกจากกลุ่มเองได้ ยกเว้นผู้ดูแลคนสุดท้ายหรือผู้จัดทริปที่ยังไม่จบ; การออกหรือถูกนำออกลบการเข้าร่วมและคำตอบของทริปในกลุ่มเพื่อไม่ให้คะแนนเก่ากลับมาเมื่อเข้าร่วมใหม่
- ผู้จัดลบทริปถาวรได้เมื่อเป็น `draft`, `cancelled` หรือ `completed`; ทริปที่กำลังโหวตหรือยืนยันแล้วต้องยกเลิกก่อน การลบต้องพิมพ์ชื่อทริปยืนยันและลบคำตอบ/ประวัติที่เกี่ยวข้อง
- ผู้ดูแลลบกลุ่มถาวรได้เมื่อไม่มีทริป `voting` หรือ `confirmed`; การลบต้องพิมพ์ชื่อกลุ่มยืนยันและลบทริปทั้งหมดของกลุ่ม
- หน้ากลุ่มของฉันสรุปทริปที่ต้องตอบคำเชิญ โหวต สรุปผล หรือตอบรับแผนจากทุกกลุ่ม

## เกณฑ์ตรวจรับ

1. กลุ่มมีสมาชิก A, B, C แต่ทริปชวน A กับ B; ผลโหวตและ “ยังไม่ตอบ” ไม่รวม C
2. B ปฏิเสธคำเชิญทริปแล้วไม่ถูกนับเป็นคนรอโหวต; B ยังอ่านข้อมูลกลุ่มได้ตามสิทธิ์สมาชิก
3. สมาชิกทั่วไปแก้กลุ่มหรือยืนยันทริปของคนอื่นไม่ได้
4. หลังเปิดโหวตผู้จัดเปลี่ยนกำหนดปิดโหวตหรือชุดตัวเลือกไม่ได้
